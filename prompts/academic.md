# Parse research articles

```
Summarize the article in a list of items. Requirements:
- Each item is claim-reason-evidence hierarchical.
- The list must be exhaustive and cover the entire document.
- Claim, reason, and evidence are all one short sentence each, highly concise, a few words only.
- Each claim must have 1 or more reasons.
- Each reason must have 0 or more evidences. When there is lack of evidence, say "Evidence: none".
- When possible, use verbatim phrasing from the original content and surround them with quotation marks.


In this format
1. **<Claim 1>**
   - Reason: <Reason 1>
     - Evidence: <Evidence 1>
     ...
   - Reason: <Reason 2>
     ...
   ...
2. **<Claim 2>**
...
```
